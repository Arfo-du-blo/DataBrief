DataBrief team settings

Choose the defaults for your team, lock what people should not change, write your own instructions, then download a ready-to-share databrief.html. Everything happens in this page, offline.

Start from an existing file (optional): load the settings of a databrief.html you made before.

Defaults and locks

A locked setting uses your value and is hidden from users. An unlocked setting is only a default: users (and links such as ?lang=fr) can still change it.

Your team's prompt text

Leave a box empty to keep DataBrief's text (translated automatically). Text you write here is used as is, in every language. The overview, the column details, the data and the "how this file is formatted" notes are always generated for each file.

"Start from DataBrief's text" uses the prompt language chosen above (English if none).
