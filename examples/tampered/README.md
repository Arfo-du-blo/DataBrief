# ⚠️ Tampered DataBrief: a demo, do not use

This folder holds a **deliberately tampered copy of DataBrief**, for the hands-on privacy check in
**[docs/verify-privacy.md](../../docs/verify-privacy.md)**. It shows what a cheating page looks like, so you can learn
to spot one with your browser's developer tools.

| File | What it is |
|---|---|
| `corrupted_databrief.html` | DataBrief + injected code that sends the **name** of the file you open (never its content) to `127.0.0.1:8765`, with a loosened security policy so the request can leave |
| `corrupted_databrief_blocked.html` | Same injected code, security policy untouched: the browser blocks the request |
| `injected_code.js` | The injected code on its own |
| `receiver.py` | The "attacker's server": serves both pages on `127.0.0.1:8765` and prints the names it receives |

```bash
python3 examples/tampered/receiver.py       # Windows: py examples\tampered\receiver.py
# then open http://127.0.0.1:8765/  (leaks)  or  http://127.0.0.1:8765/blocked  (blocked), press F12 > Network
```

**Safe by design:** everything stays on your computer (`127.0.0.1` means "this computer", and the receiver accepts
no connection from elsewhere). Both pages show a red **DEMO** banner. They're generated by `build.ps1` from
`databrief.html` and are **never published**: GitHub/GitLab Pages, the releases and the Docker images only contain
the real files, and the tests check that.

**Never use these pages with real data, and never host them.**
